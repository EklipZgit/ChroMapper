In this map, you can see how to clone ring lights and bind them to the existing ring.
This does not produce a separate controllable ring, but does duplicate panics 2-light-band ring to make it a 4-light-band ring while removing the unlit two bands from default panic environment.
This is effectively still "one ring" in this case, but it has more light ids.


While in the basic events view, use Alt+P and PageUp PageDown to find the ring lights page, where you will see extra light ids tacked on to the end of the light lanes.

This sample includes some sample step/prop bounces that you can do to achieve effects with a ring as well.
